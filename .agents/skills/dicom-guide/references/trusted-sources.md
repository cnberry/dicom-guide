# Trusted source routing

Use one to three links that directly support the explanation. Prefer patient-facing
material for the first link and a technical or primary source when it adds value.
Never send DICOM pixels, metadata, report text, names, dates, coordinates, or a
patient-specific combination of facts to a search engine.

## Default source hierarchy

1. **The supplied radiology report** for what the interpreting radiologist concluded.
   Attribute it as supplied context; it has no public link.
2. **ACR/RSNA RadiologyInfo** for scan types, report structure, and patient-facing
   terminology:
   - [How to read radiology reports](https://www.radiologyinfo.org/en/radiology-reports)
   - [How to read a brain MRI report](https://www.radiologyinfo.org/en/info/article-brain-mri-report)
   - [How to read a head CT report](https://www.radiologyinfo.org/en/info/article-head-ct-report)
3. **The DICOM Standard Committee** for format, metadata, and interoperability:
   - [Current DICOM Standard](https://www.dicomstandard.org/current/)
   - [DICOM security](https://www.dicomstandard.org/using/security)
4. **Government and professional sources** for condition, safety, and treatment
   background:
   - [National Cancer Institute: brain tumors](https://www.cancer.gov/types/brain)
   - [FDA: MRI](https://www.fda.gov/radiation-emitting-products/medical-imaging/mri-magnetic-resonance-imaging)
   - [FDA: CT](https://www.fda.gov/radiation-emitting-products/medical-x-ray-imaging/computed-tomography-ct)
   - [MedlinePlus diagnostic imaging](https://medlineplus.gov/diagnosticimaging.html)
5. **Peer-reviewed literature** for narrow technical questions. Prefer systematic
   reviews, consensus guidelines, or primary research indexed by
   [PubMed](https://pubmed.ncbi.nlm.nih.gov/). State when evidence is preliminary,
   population-specific, or not directly applicable to the displayed study.

## Source behavior

- Link to the exact page, guideline, or paper—not a search result.
- Confirm that the page supports the adjacent claim.
- Use current sources for medical guidance; check dates and revisions.
- Do not imply that a general source confirms the person's image finding.
- Do not quote at length. Translate the useful point in plain language.
- If network access is unavailable, offer the stable links above and say the source
  was not rechecked during this session.
